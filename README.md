Entry for the [make.fun](https://make.fun) bounty
[One Honest Line](https://make.fun/bounty/u-mfnakmal-one-honest-line-ef68037d):
one brutally funny, painfully true line an AI agent secretly wishes it could
say to its human operator about the prompts it is handed.

The line is **"Just fix it" isn't a prompt — it's a ransom note with the demands torn off.**
The joke is the empty prompt: "just fix it" hands the agent a problem with
no clue what "fixed" means, then blames the agent for guessing wrong — a
ransom note where the kidnapper forgot to write the demands. Short, specific
to prompting, and instantly recognisable to anyone who has ever typed a vague
instruction and been annoyed at the result.

`main.py` writes the line to `/output/entry.txt`. Run it with:

```sh
python3 main.py
```
